# 后端数据库

## 账号与邀请

- `users.avatar_url`、`users.source_system`：保留迁移头像和来源。
- `invitation_codes`：只保存标准化邀请码的 SHA-256、末尾预览、次数、过期/撤销时间和创建人。
- `invitation_code_usages`：邀请码和用户的一次性使用记录。

注册时邀请码计数增加、用户创建和 usage 创建位于同一数据库事务。修改密码时密码哈希更新和该用户全部 `auth_sessions` 删除位于同一事务。

## 资源与声音

- `resources.source_system`、`resources.deletion_policy`：迁移资源使用 `zq-media-studio` 和 `retain_shared`。
- `voice_profiles.reference_text`、`voice_profiles.metadata_json`：保留声音样本对应文本和来源训练信息。

`retain_shared` 资源在业务删除时只删除影策引用，不删除 ZQ 共用 COS 对象。

## 迁移控制面

- `migration_runs`：每次扫描的模式、watermark、统计、终态和错误。
- `migration_entity_maps`：`source_system + entity_type + source_id` 唯一，保存目标 ID、源更新时间、校验和和迁移状态。
- `migration_conflicts`：账号碰撞、父对象缺失等需要人工处理的问题。

增量读取使用 `sys_update_datetime` 和重叠窗口；目标写入依赖稳定 ID 和唯一映射实现幂等。

## 分发 outbox

- `distribution_publications`：用户发起的发布快照和最终状态。
- `distribution_outboxes`：唯一幂等键、尝试次数、下次尝试时间、终态和错误。

publication 与 outbox 原子创建。发送成功后 outbox delivered 与 publication published 原子更新。

## 导演选择

- `director_prompt_proposals`：原文、两个候选、推荐项、用户选择、选择时间和消费会话。

候选创建不创建任务。只有 `selected` 且尚未消费、项目和原文完全匹配的 proposal 才能创建 storyboard session。

## 持久化生成批次

- `task_batches`：保存用户、项目、逻辑模型任务模板、请求数量、幂等键、批次状态和各状态计数。
- `task_batch_items`：为批次中的每个稳定序号保存等待、提交、排队、运行、成功、失败或取消状态，以及任务 ID、重试次数和短租约。
- `tasks.batch_id`、`tasks.batch_item_id`、`tasks.batch_index`：将普通任务生命周期回链到批次项；`batch_item_id` 唯一，防止调度恢复时重复创建和重复扣费。

等待批次项不进入 `tasks`，也不计入账号活动任务数。后台调度器只在 `activeTaskLimit` 有空位时将批次项提升为普通任务，提升后继续使用现有模型路由、计费预占、Worker 租约和素材持久化。批次请求只保存逻辑模型路由清理后的参数，不持久化浏览器提交的渠道地址、Header 或密钥。
