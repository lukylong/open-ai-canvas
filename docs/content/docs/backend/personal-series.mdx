# 个人素材系列

入口是「素材库 → 我的素材 → 系列管理」，也可在系列卡片点击「管理系列」。外层展示一级系列入口（含空系列）和未归组素材；已归组素材不再在外层单独出现。进入系列后只显示直属素材，子系列通过独立入口进入，避免父子或兄弟系列混在同一张表中。

新增/编辑素材表单可选择「所属系列」；在系列内点击新增会默认选择当前系列。保存先确认素材已在服务端持久化，再设置成员归属，全部成功后才提示完成；失败重试沿用同一个素材 ID，不重复新建。

## 接口

全部接口使用现有登录 Cookie 与 `{ code, data, msg }` 信封，操作只允许当前账号的对象，管理员也不能借此管理其他账号的个人素材。

| 方法与路径 | 请求 / 响应 |
| --- | --- |
| `GET /api/personal-series` | `{ series, memberships }`，只返回当前用户系列及有效素材成员 |
| `POST /api/personal-series` | `{ name, parentId }`，创建并返回 `{ series }`；空 parentId 为一级 |
| `PATCH /api/personal-series/:id` | `{ name, parentId }`，保存名称与上级；禁止环路与超过 8 级 |
| `DELETE /api/personal-series/:id` | 删除分组、成员恢复自动归组；有子系列时拒绝；不删除任何素材 |
| `POST /api/personal-series/members` | `{ assetIds, seriesId }`，原子移动 1～1000 个有效素材；空 seriesId 表示移出 |
| `PUT /api/personal-series/:id/cover` | `{ assetId }`，仅允许当前系列或子系列中的有效图片；空字符串恢复自动封面 |

名称去除前后空格，长度 1～80 字，同级不允许重复。封面移出有效范围时在同一事务中清理，失败回滚成员归属和封面，不出现半成功。

## 与任务及分发的边界

整理不改写 Asset、Resource、素材版本和生成任务/批次血缘；数据库使用独立系列与成员表。未手动归组的素材继续沿用已有任务系列逻辑。

整理不自动发布。只有用户显式点击同步分发时，后端才读取保存的手动系列，将其写为 `series_id`、`series_type=manual`、`series_label`，保留原始批次与任务元数据。客户端不能覆盖服务器保存的手动系列。重命名、移动、移出会产生递增的分发版本，避免错误复用旧系列的分发记录；既有分发队列不会被后台批量改写。

### 多层级同步名称

每张素材独立读取自己的直属系列，即便一次批量请求包含多个层级的素材，也不能用所选上级系列的名称覆盖子系列。例：`美食 / 家常菜 / 蒜蓉虾` 中的图片，接收端 `series_label` 为 `蒜蓉虾`；直接位于 `美食` 的素材才使用 `美食`。

- `series_id` 使用直属系列的稳定 ID，不按名称合并。不同父级下的同名系列仍是不同系列。
- `series_path` 保存完整名称路径；`series_path_ids` 按根到直属系列保存 ID 路径；`series_parent_id` 保存直属父 ID。三者由后端重建，忽略客户端传入值；不将完整路径冒充显示名称。
- 读取成员与祖先链使用同一账号事务锁。祖先改名、移动后，下次显式分发更新路径与版本，但不改变素材直属系列名称；直属系列改名才更新其显示名称。
- 移出手动系列后清除层级字段，恢复原生成任务归组。支持最多 8 级，遇到缺失父级、循环或跨账号父级时拒绝同步，不错误降级成单图系列。
- 当前分发接收协议仍以 `series_id` 扁平归组；完整层级作为元数据保留，并不表示分发平台已新增树形管理界面。

## 验收与上线

分发达到终止条件（例如达到重试上限）后，outbox 标记 `stopped` 并清空下次重试时间，保留失败原因和尝试次数。worker 只领取发布状态仍为 `pending` 的任务，历史终止失败不会再被自动领取；用户显式重试才将次数重置为 0。暂时性故障仍保留原有有限重试。

需先迁移 schema v7 → v8，再发布后端与前端。数据库迁移只新增系列和成员表。线上迁移与真实浏览器验收仍由发布流程单独执行，本地测试通过不代表已经上线。
