# 功能总览

影策继续作为唯一创作界面。ZQ Media Studio 只作为迁移源，原聊天式创作工作台、会话、任务、通知、审计和用户 Skill 不进入新系统。

## 已纳入

- 邀请码注册、管理员邀请码管理、用户密码修改和全会话撤销。
- ZQ 用户、有效/历史邀请码、私有素材、素材版本、COS 引用、声音档案的只读迁移；只把 `generation_task_id`、`batch_id`、批次起始序号和素材序号作为素材系列血缘写入，不迁移旧任务实体。
- 素材库按批次、生成任务或单素材展示系列；可对单素材、当前选择或整个系列手动发布到独立素材分发平台，单次 API 最多接收 1000 个素材。发布快照、outbox、幂等键、签名、重试和取消均在服务端完成。
- ComfyUI 多 Provider 工作流适配器；工作流文件随 Git 版本化，并以逻辑模型/规格价格档进入现有路由与计费。
- 专业导演两阶段入口：先比较“叙事优先”和“视听优先”，再由用户选择；选择前不创建生成任务。
- 角色声音档案继续用于 TTS；异步音频协议可获得声音样本、参考文本和音色元数据。
- 管理后台“用户内容”按用户、类型、状态和来源筛选任务与媒体；管理员可查看提示词、请求参数、结果、错误，并通过服务端权限校验预览或下载其他用户素材。

## 明确保留在系统边界外

- ZQ 创作工作台 UI、历史消息/对话、旧生成任务实体、通知、请求审计、用户 Skill。
- 自动发布、公共素材发现、跨系统实时双写和新素材物理复制。
- 旧系统对象的物理删除。迁移资源使用 `retain_shared` 删除策略。

## 用户影响

- 被迁移用户沿用原 bcrypt 密码，但需要在影策重新登录一次。
- 新注册必须使用邀请码；邮箱可空且不要求邮箱验证码。
- 只有用户名和非空邮箱同时指向同一个影策账号时才合并；其余碰撞进入冲突表。
- 手动发布仍是唯一分发入口；创建或生成素材不会自动产生发布记录。批量创建只负责逐素材幂等入队，并明确返回成功和失败明细。
