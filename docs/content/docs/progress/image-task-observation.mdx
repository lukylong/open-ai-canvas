# 图片任务长耗时状态同步

图片生成默认观察窗口仍为 10 分钟，但窗口到期时，只要已知后台任务处于 queued / running，就继续查询同一个任务，不创建重试任务，也不改写后台状态。

- 长时间运行显示“后台仍在生成中，请勿重复提交”；排队显示对应排队提示。
- 暂时断网保持最近一次状态，并提示重新同步。401 / 403 / 404 则结束监听，避免无效请求无限循环。
- 超过默认窗口后，查询间隔至少为 5 秒。
- 后端 succeeded / failed / cancelled 是结束依据；调用方显式设置的 timeoutMs 仍生效。
- 退出页面、取消观察或最后一个订阅者离开时，释放观察任务和 AbortSignal 监听器，不取消服务端生成。
- 本机即梦、文本 SSE，以及其他媒体的默认等待逻辑保持原有行为。

不调整模型、输出分辨率、采样步数、后端任务期限或计费规则。高分辨率图生图仍可能耗时较长，这次修复不以降低画质换取速度。

回归覆盖：18 分钟生成与排队、临时网络断开后恢复、明确服务端失败、授权失败、显式超时、观察取消及重新订阅。

已有成功任务的结果保持原位；重新进入页面时通过现有恢复机制查询后台任务状态，不需要重复提交。
